# EGA Explorer 빠른 사용 안내

이 앱은 보고된 결과와 같은 자료에 남아 있는 다른 결과들을 함께 살펴보는 도구입니다.

1. **Define:** GSS 예제로 시작합니다. HAPPY·TRUST·FAIR가 초점 결과로 표시됩니다.
2. **Map:** EGA 이웃을 살펴보고 community와 15·25·35% 경계를 바꿔 봅니다.
3. **Results:** 미보고 결과와 초점 결과를 비교합니다. |t|는 효과크기가 아니라 추정치와 표준오차의 비율입니다. 계수와 구간도 함께 봅니다.
4. **Interpret & export:** 비교의 의미를 적고 전체 결과와 보고서를 내려받습니다.

새 데이터 분석도 시험하려면 **My CSV data → Try a synthetic dataset**에서 가상 자료를 내려받아 올리세요. 예측변수는 X, 결과변수는 Item01–Item12입니다.

**온라인 앱에 올리는 자료는 분석 서버로 전송됩니다. 공개 자료나 가상 자료만 사용하세요.** 비밀 자료·개인 식별 자료·접근 제한 자료를 올리지 마세요. GitHub 이슈도 공개되므로 오류 제보에 민감한 자료를 첨부하지 마세요.

로컬 실행법과 자세한 방법·한계는 [README](README.md)에 있습니다. 공저자 검토에서는 화면의 이해 가능성, 예제와 새 데이터 분석, 경계 변경, 결과 내보내기를 확인해 주시면 됩니다.
