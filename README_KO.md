# EGA Explorer 3.0.1 사용 안내

보고된 결과를 같은 자료에 남아 있는 미보고 결과와 비교하는 앱입니다. 같은 주장을 검토할 수 있는 대안들에서도 결과가 이어지는지 살펴보고, 보고된 결과만 두드러질 때에는 결과를 보고 고른 선택, 측정의 질, 실제 연관, 비교 집합의 구성이라는 설명들을 검토합니다.

## 실행

이 폴더에서 다음을 실행합니다. 설치는 `renv.lock`의 195개 패키지 버전을 프로젝트의 `.library`에 복원합니다. 기존 사용자 라이브러리는 유지됩니다. 검증 환경은 R 4.4.1입니다.

```sh
Rscript install_dependencies.R
Rscript run_app.R
```

브라우저에서 `http://127.0.0.1:7860`을 엽니다. Mac에서는 `Start_AMPPS.command`로 실행할 수도 있습니다. 앱 실행 중 패키지를 자동 설치하지 않습니다.

## 네 화면

1. **Define:** 보고했거나 이론에 따라 선택한 결과변수, 예측변수, 공통 모형을 지정합니다. 분석 가능한 모든 결과변수에 같은 모형을 적합합니다.
2. **Map:** 커뮤니티별 색상으로 모든 결과변수를 표시하고, 마름모로 초점 결과변수를, 진한 테두리로 현재 비교할 이웃을 표시합니다. GSS 이웃 11개에는 질문·응답 선택지·응답자 정보를 표시하며 다운로드에도 보존합니다. 문항 내용·응답 형식·응답자 구성을 함께 읽고, 필요하면 15·25·35% 거리 경계도 비교합니다.
3. **Results:** |t|로 결과의 위치를 보고, 각 계수와 신뢰구간으로 크기와 방향을 읽습니다. 비교 집합과 통계적 조건을 정당화할 수 있는 업로드 분석에는 선택적으로 순위합 참조 검정을 실행합니다.
4. **Interpret & export:** 같은 주장의 대체 측정치와 관련 영역의 결과를 구분하고, 비교가 지지·설명의 범위·새 질문에 주는 정보를 기록합니다. 전체 결과와 재현 가능한 보고서를 내려받습니다.

## 순위합 참조 검정

Results 하단에서 이번 주장의 비교 집합과 보고된 부분집합을 각각 정합니다. 초점 결과변수 가운데 이번 주장에 속하는 것만 보고된 집합에 포함할 수 있습니다. |t| 또는 정해 둔 방향의 t를 선택하고, 결과를 보기 전에 비교 집합과 통계량을 정한 근거, 다음 두 통계적 조건 중 적용하는 조건의 근거를 기록합니다.

- 관측된 통계량을 조건으로 같은 크기의 모든 부분집합이 똑같이 보고될 수 있는 조건.
- 보고된 라벨이 고정된 경우, 후보 라벨을 바꾸어도 통계량의 결합분포가 같은 조건.

문항을 같은 주장에 대한 대안으로 볼 수 있다는 판단과 이 통계적 조건의 정당화는 별도로 기록합니다. 앱은 연구자의 설명을 보관합니다.

계산은 관측된 통계량을 고정하고 보고 여부 라벨을 바꾸는 정확한 순열 계산입니다. 가장 높은 순위를 1로 두고 동점에는 평균 순위를 씁니다. 보고된 순위합, 참조 p값, 가능한 조합 수, 도달 가능한 최소 p값과 .05 기준의 실제 도달 비율을 표시합니다. 화면에서는 20만 조합까지 전수 계산하며, 이를 넘으면 비교 집합을 그대로 둔 채 계산 한도를 안내합니다.

GSS 예시는 추정치·구간·순위 비교를 제공합니다. 서로 다른 문항의 보고 확률이나 라벨 대칭 조건이 정당화되지 않아 참조 p값은 붙이지 않습니다. 같은 모형·11개 결과변수·|t| 순서에서 Health와 Life가 Trust와 Fair보다 위에 있다는 구체적인 비교는 유지합니다.

검정을 실행했다면 ZIP에는 가정과 근거, 순위와 참조분포, `reproduce_reference.R`이 들어갑니다. ZIP을 푼 폴더에서 이 코드를 실행하면 같은 계산을 재현합니다. 비교 설정이 바뀌면 이전 p값은 보고서에서 빠지고 재계산이 필요합니다.

## 자료와 버전

가상 자료를 시험하려면 **My CSV data → Try a synthetic dataset**을 사용합니다. 예측변수는 X, 결과변수는 Item01–Item12입니다. 예제는 소프트웨어 검증용입니다.

온라인 앱에 올리는 자료는 해당 분석 서버로 전송됩니다. 로컬 실행과 온라인 배포를 구분해 사용하세요. 업로드한 원자료는 내보내기에서 명시적으로 선택할 때만 ZIP에 포함됩니다.

이 저장소는 EGA Explorer 3.0.1의 소스입니다. 실제 로컬 검증 내역은 [TEST_REPORT](TEST_REPORT.md)에 정리합니다.
